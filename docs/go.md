# Go Environment

## Installed Version

Verify:

```bash
go version
```

---

## Environment

GOROOT

```bash
go env GOROOT
```

GOPATH

```bash
go env GOPATH
```

---

## Create a Project

```bash
go mod init my-project
```

---

## Run

```bash
go run main.go
```

---

## Build

```bash
go build
```

---

## Format

```bash
go fmt
```
